# Studi Kasus 2 Simulasi Skalabilitas Paralel Deteksi Polusi Udara HPC OpenMP
Studi kasus ini mengimplementasikan komputasi paralel CPU menggunakan OpenMP untuk mempercepat simulasi dispersi polusi PM2.5 multi-grid. Proyek ini mendemonstrasikan evaluasi metrik HPC (Speedup, Scalability, dan Throughput), optimasi arsitektur multi-core, serta penyiapan naskah batch job SLURM standar superkomputer.
